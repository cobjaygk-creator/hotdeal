# 핫딜이쥬 UI 디자인 기준

핫딜 리스트를 기준 화면으로 삼고 랭킹·패밀리세일·상품 상세가 같은 화면 언어를 사용한다.

## 공통 레이아웃

- PC 콘텐츠 최대 폭은 `--maxw`, 좌우 여백은 토큰 간격으로 통일한다.
- 상단 헤더는 브랜드, 주요 메뉴, 검색, 계정 순서다.
- 페이지 제목 아래에 상태 안내를 두고, 그 아래 카테고리 칩과 보기 전환을 배치한다.
- 본문은 `1fr + 300px` 2열이다. 우측에는 인기 딜, 알림, 광고를 둔다.
- 모바일에서는 우측 레일을 본문 아래로 이동하고 본문은 한 열로 표시한다.

## 리스트 행

- 썸네일은 88px 정사각형이다.
- 정보 순서는 몰·출처, 제목 한 줄, 할인율·가격·배송비다.
- 오른쪽에는 최저가 배지, 댓글 수, 상대 시간을 둔다.
- 행 사이에는 1px 구분선만 사용하며 카드 그림자와 좌측 색상 보더는 사용하지 않는다.
- 목록형과 4열형은 같은 데이터를 사용하고 `localStorage`에 선택 상태를 저장한다.

## 상세 모달

- 모달은 `1040px`, 최대 높이 `960px`, 내부 스크롤 구조다.
- 고정 헤더는 브레드크럼, 이전·다음, 링크 복사, 닫기 순서다.
- 히어로는 `400px 이미지 + 상품 정보` 2열이다.
- 상품 정보는 몰·출처, 제목, 할인율·가격, 정가, 판정, 배송·카테고리·반응, CTA 순서다.
- 본문은 가격 비교, 광고, 가격 변동, 원문 내용, 원문 게시글 순서다.
- 댓글은 본문 아래 구간의 우측 열에 둔다.
- 가격 샘플이 3개 미만이면 가격 변동 섹션을 만들지 않는다.

## 상태

- 로딩: 모달 내부에 로딩 문구를 표시한다.
- 이미지 없음: 토큰 기반 회색 이미지 영역을 표시한다.
- 종료 딜: 제목·가격을 회색으로 바꾸고 할인율·배지를 숨긴다.
- 수집 지연: 마지막 성공 수집 시각과 소스 상태를 표시한다.
- 빈 목록: 원인과 다음 행동을 한 문장으로 안내한다.

## 화면별 데이터 매핑

| 화면 | 공통 구조 | 화면 전용 항목 |
| --- | --- | --- |
| 핫딜 | 리스트 행·우측 레일 | 할인율, 가격, 배송비 |
| 랭킹 | 리스트 행·우측 레일 | 순위, 인기 점수 |
| 패밀리세일 | 리스트 행·우측 레일 | 진행 상태, 기간, 할인, 입장코드 |
| 상세 | 공통 모달 | 가격 비교, 원문, 댓글 |
