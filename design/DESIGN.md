# 핫딜이쥬 UI 기준

## 시각 방향

정보 밀도가 높은 커머스 피드. 파란색은 구매·선택·상태에만 사용하고, 상품명과 가격이 화면에서 가장 먼저 읽혀야 한다.

## 공통 구조

1. 상단 헤더에는 서비스 전역 메뉴를 한 번만 둔다.
2. 각 화면은 `페이지 제목과 상태 → 필터/정렬 → 목록` 순서를 따른다.
3. 목록은 얇은 구분선으로 구획하고, 카드 장식보다 상품 정보의 대비로 스캔성을 만든다.
4. 우측 레일은 데스크톱의 보조 정보이며 모바일에서는 목록 아래로 이동한다.

## 딜 행

- 왼쪽: 상품 이미지와 찜.
- 중앙: 판매처·출처·분류, 상품명, 가격과 배송 조건.
- 오른쪽: 구매, 댓글, 시각.
- 가격과 구매하기는 항상 한눈에 확인할 수 있어야 한다.

## 상세

가격과 구매 링크를 최상단에 두고, 이미지·설명·가격 비교/흐름·댓글 순서로 읽는다. 모달 동작과 원문 링크, 찜, 댓글, 가격 그래프는 유지한다.
